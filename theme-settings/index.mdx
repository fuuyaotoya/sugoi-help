## テーマ設定はどこにありますか

1. Shopify 管理画面で **オンラインストア → テーマ** を開きます
2. カスタマイズしたいテーマで **カスタマイズ** をクリックします
3. テーマエディタの左側で、一番下の **テーマ設定** (歯車のアイコン)を開きます

テーマ設定で変更した内容は、ストア全体(すべてのページ)に適用されます。ページごとの内容は「セクション」で設定します → [セクションリファレンス](/features/sections/sg-media-hero)

## SUGOI テーマの設定グループ

テーマ設定には、Shopify 標準の設定(ロゴ・色・タイポグラフィなど)に加えて、SUGOI 独自のグループがあります。

| 設定グループ | 内容 | 詳細 |
|---|---|---|
| **テーマライセンス** | 利用するストアの登録(1購入1ストア) | [詳細](/theme-settings/license) |
| **AIチャット連携** | AIチャットの接続・プライバシー・計測 | [詳細](/theme-settings/chat) |
| **ギフト・のし** | 商品ページでのし・包装・名入れの入力 | [詳細](/theme-settings/gift) |
| **購入時の案内** | 購入ボタン下の送料・決済・返品の案内 | [詳細](/theme-settings/purchase-confidence) |
| **検索向け商品情報** | Google 等への返品・配送情報の提供 | [詳細](/theme-settings/structured-data) |
| **写真と余白** | エディトリアルレイアウトの切り替え | [詳細](/theme-settings/editorial) |
| **お気に入りとカラーチップ / アイコンと画面の動き** | 表示の細部 | [詳細](/theme-settings/appearance) |

## Shopify 標準の設定

ロゴ・色・タイポグラフィ・ボタン・カード・カート・SNS などの標準設定は Shopify の公式ガイドに共通するものです。日本語のガイドは [Shopify ヘルプセンターの「テーマ設定をカスタマイズする」](https://help.shopify.com/ja/manual/online-store/themes/customize-theme/edit-theme-settings) を参照してください。

<Note>
設定変更後は、テーマエディタ右上の **保存** を忘れないでください。プレビューはリアルタイムに反映されますが、保存するまで公開ストアには適用されません。
</Note>
