SUGOI Theme は単体で完結するテーマですが、**SUGOI Chat** アプリと組み合わせると、ストアフロントにAIチャットコンシェルジュが宿ります。閉店後の来店者を、チャットが店員として迎える — サイズ・ギフト・配送という「買い物が止まる3点」を会話で解決する接客担当です。

このほか、売れ筋ランキング質問・コーデ提案・お気に入り比較の商品相談・有人サポートへの引き継ぎ(根拠を示せなかった回答の時のみ)に対応します。回答には「根拠: 商品データ / 配送ルール」のような出典チップが付き、お客様が情報源を確認できます。

## テーマ側の有効化手順

SUGOI Chat アプリをストアにインストールした後、テーマ側で接続します:

1. SUGOI Chat をインストールし、アプリ側に案内された接続先 URL を控える
2. テーマ設定 → **AIチャット連携** → 「AIチャットの接続先URL」に入力する
3. 保存

未設定の間、チャット UI は **何も出力しません**(fail-closed 設計)。誤動作の心配なく、他の設定を先に進められます。

## テーマ側の設定

テーマ設定(**テーマ設定 → AIチャット連携**)で、接続先URL・プライバシー関連・ランキングとコーデ提案の出典・売上計測を設定します。設定項目の詳細は [AIチャット連携(テーマ設定ガイド)](/theme-settings/chat) を参照してください。

## 配送・納期への回答

チャットへの「間に合う?」という質問には、商品ページに表示している配送の案内と整合する回答を返す設計です。配送日程の計算ルールは連携アプリ側で管理するため、場当たりの回答を出しません。テーマ側の表示は [配送・送料情報セクション](/features/sections/sg-shipping-info) で設定します。

## プライバシーと安全な設計

- チャットの回答テキスト・商品データはすべて安全な描画のみ(HTML 注入不可)
- 注文状況回答に使う情報は注文番号・状況・追跡URL 等**最小限**に絞り、氏名・住所・メール・電話は含みません
- お客様の好み(サイズ等)の保存は、画面の同意チェックボックスが ON の時のみ行われます
- 個人情報をAIに渡さない設定(`sg_chat_customer_hint` / `sg_chat_order_context`)は既定で OFF です

## 料金プラン

| 条件 | Free | Standard | Pro |
|---|---|---|---|
| 基本料 | $0 | **$39 / 30日** | **$99 / 30日** |
| 主な用途 | お試し | 買い物客への接客 | 接客 + 朝の報告 + 店主・スタッフの相談 |
| 接客枠 | 30回 / 月 | **500回 / 30日** | **2,000回 / 30日** |
| 画像検索 | 5回 / 月 | 含む(接客と同じ枠) | 含む(接客と同じ枠) |
| 画像検索の索引対象 | — | 最大1,000商品 | 最大5,000商品 |
| 朝のAIレポート | — | — | 1日1回自動生成 |
| 店主・スタッフの相談AI | — | — | 含む(1日200リクエスト) |
| 超過利用 | なし(枠で停止) | $0.08/回(上限を選んで有効化) | $0.08/回(上限を選んで有効化) |
| 無料お試し | — | 14日 | 14日 |

「1回」= 購入者の送信1件に対して正常に完了した接客処理(文章1件または画像検索1件)。AI内部の検索・生成は数えません。超過利用は初期状態で OFF で、店舗が追加料金の上限($20 / $50 / $100)を選んで明示的に有効化した場合のみ課金されます。
