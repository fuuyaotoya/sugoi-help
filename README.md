# sugoi-help

SUGOI Theme 公式マニュアルサイト(Mintlify / 日本語+英語)。

- 対象: SUGOI Theme + SUGOI Chat / SUGOI Account 連携
- 構成: `docs.json`(Mintlify 設定)+ `*.mdx`(ja)/ `en/*.mdx`(en)
- 運用: main ブランチ = 公開。開発は feature ブランチ + PR プレビューで確認してマージ

## ローカル開発

```bash
npm i -g mint
mint login
mint dev
```

## ライセンス・注意

- コンテンツは SUGOI Theme 製品ドキュメントのみを扱う(受託案件の情報は含めない)
- スクリーンショットは実証ストア(sugoi-fit)から撮影したものを使用
