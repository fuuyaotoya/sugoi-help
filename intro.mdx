## 単体で動く。合わさると、もっと。

SUGOI Theme は、Shopify 公式テーマ **Dawn** を基盤に、日本のECに必要な機能を最初から備えたテーマです。

**テーマ単体で、すぐ店舗として機能します。** AI アプリを入れなくても、のし・ギフト対応、お届け希望日時、配送目安の表示、特定商取引法の表示といった、日本の商いに必要な買い物の流れは最初から揃っています。

そこに SUGOI のアプリを組み合わせると、テーマは **AI ストア** へと覚醒します。

## このマニュアルについて

このマニュアルは、SUGOI Theme を導入した店舗の方向けの**取扱説明書**です。

- **[テーマ設定ガイド](/theme-settings)** — テーマのカスタム設定(テーマ設定・各セクションの設定項目)の説明。まずここから
- **[機能ガイド](/features/japan-ec)** — 日本EC標準装備(のし・ギフト・配送など)の機能説明
- **[連携ガイド](/integrations/sugoi-chat)** — SUGOI Chat / SUGOI Account との組み合わせ方と設定

## セットアップの基本の流れ

1. **テーマを適用** — テーマファイルをストアへ追加し、公開します
2. **テーマ設定を確認** — テーマ設定の SUGOI 各セクション(ギフト・配送・AIチャットなど)を店舗に合わせて設定します → [テーマ設定ガイド](/theme-settings)
3. **コンテンツを配置** — Theme Editor でセクションを並べ、各ページを組み立てます → [セクションリファレンス](/features/sections/sg-media-hero)
4. **(任意)アプリを追加** — SUGOI Chat / SUGOI Account をインストールして覚醒します → [連携ガイド](/integrations/sugoi-chat)
