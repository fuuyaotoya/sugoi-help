A participatory section that asks shoppers to make light choices — how much ease do you like, where should the hem fall — and displays the answers as a "fit card." It never scores sizes or proposes an "ideal size"; instead, it turns preferences into the starting point of product selection.

![The fit playroom section](/en/images/sg-fit-playroom.png)

## How to add it

Open the theme editor (in the admin: "Online store → Themes → Customize"), and on the page where you want it, choose **"Fit playroom"** from "Add section". It can be added to any page type. Proven on home pages.

## Settings

The settings look numerous, but every default text is already filled in — adding the section as-is just works. Each item exists so you can tune the wording to your store.

### Introduction

- **Eyebrow**: The small intro label (default: Play a little, learn a little about yourself.)
- **Signature**: The text shown as the section's name (default: Fit Playroom)
- **Heading**: The section heading (default: A fit that's yours.)
- **Intro text**: The section's descriptive text
- **Patch label**: The label placed over the embroidered-style patch (default: The only rule)
- **Patch message**: The text at the center of the patch (default: There is no perfect size. Only a fit that feels like you.)
- **Patch footer**: The small text at the bottom of the patch (default: YOUR FIT ✳)
- **Reassurance note**: A note communicating that no scoring takes place

### Quiz board

- **Quiz label**: The heading around the quiz
- **Ease question**: The question for choosing ease (default: How much ease feels like you?)
- **Hem question**: The question for choosing hem length (default: Where should the hem fall?)
- **Size-label question**: The question "Same size label, same fit?"
- **Size-label answer**: The one-line answer to the question above (default: Not necessarily.)
- **Size-label explanation**: Supplementary explanation of the answer (default: Size labels are a starting point, not a promise of fit. Dimensions differ from style to style.)
- **Quiz footer**: The text at the bottom of the quiz board

### Fit card

- **Card label**: The label of the results card (default: Your fit card)
- **Card heading**: The card's heading
- **Size note**: A note attached to the card. **Keep it free of numbers.** This section makes no size recommendations or guarantees (default: Let's check together)
- **Link label**: The text of the link beneath the card (default: Browse products)
- **Link**: The destination URL (a collection page, for example)
- **Note under the link**: A small note beneath the link

### Color schemes and spacing

- **Section color scheme**: The section's color scheme
- **Quiz board color scheme**: The quiz area's color scheme
- **Patch color scheme**: The patch area's color scheme
- **Fit card color scheme**: The fit card's color scheme
- **Top / Bottom**: Padding above and below the section (default 72 / 28)

## Blocks

### Ease option (limit 3)

An "ease" choice for the quiz. With none added, the section runs on the default three options (Slim fit / Just-right ease / Relaxed and easy).

- **Label**: The option's text
- **Silhouette**: Choose the silhouette figure shown for the option from "Slim / Moderate ease / Relaxed"
- **Make it pre-selected**: Check to have it selected from page load on (recommended for one only)

### Hem option (limit 3)

A "hem length" choice for the quiz. With none added, the section runs on the default three options (Around the ankle / Over the shoe / Still deciding).

- **Label**: The option's text
- **Make it pre-selected**: Check to have it selected from page load on (recommended for one only)

<Note>
This section never scores shoppers' body types or presents a "correct size". Keep the size note free of numeric expressions (cm values and the like). The design assumes per-product measurements are checked in the product page's size guide.
</Note>
