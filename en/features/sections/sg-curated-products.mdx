A section for arranging hand-picked products, chosen one by one. Each product can have an alternate image, a short display title, and a caption — a grid built for merchandising that explains "why we recommend this product."

![The curated products section](/en/images/sg-curated-products.png)

## How to add it

Open the theme editor (in the admin: "Online store → Themes → Customize"), and on the page where you want it, choose **"Curated products"** from "Add section". It can be added to any page type (except header and footer areas). Proven on home pages.

## Settings

- **Eyebrow**: A small label shown above the heading (default: A carefully selected lineup)
- **Heading**: The section heading (default: Items for everyday life)
- **View-all link label**: The text of the "view all" link beside the heading (default: View all)
- **View-all link**: The destination URL (a collection page, for example)
- **Color scheme**: The section's color scheme
- **Image ratio**: Choose the product image aspect ratio from "Adapt to image / Portrait (4:5) / Square / Landscape (4:3)" (default: portrait)
- **Inner image spacing**: Relative to the "spacing around photos" theme setting, adjusts this section only from 0-200%. 0% removes the spacing (default 100)
- **Top / Bottom**: Padding above and below the section (default 64 / 64)

## Blocks

### Product

Adds one product to display. There is no limit on the number.

- **Product**: Choose the product to display
- **Alternate image**: When blank, the product image is used. Set this to place an image other than the registered product photos
- **Short display title**: When blank, the product name is used. Set this for a shortened label that reads well in the grid
- **Caption**: A short description beneath the product (e.g., The most-picked classic)

<Note>
"Curated products" is manual selection. Products are never added automatically — refresh the lineup by swapping blocks in this section. Order can be changed by dragging.
</Note>
