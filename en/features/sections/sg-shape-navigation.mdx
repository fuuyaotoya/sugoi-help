A section that arranges cards — each with an image, title, body, and link — to guide shoppers to the collections they're after. Well suited to denim silhouettes (straight, wide, and so on) and category-by-category guidance.

![The shape navigation section](/en/images/sg-shape-navigation.png)

## How to add it

Open the theme editor (in the admin: "Online store → Themes → Customize"), and on the page where you want it, choose **"Shape navigation"** from "Add section". It can be added to any page type (except header and footer areas). Proven on home and collection pages.

## Settings

- **Eyebrow**: A small label shown above the heading (e.g., FIND YOUR SHAPE)
- **Heading**: The section heading
- **Body**: Descriptive text beneath the heading
- **Footnote**: A small note shown at the bottom of the section
- **Anchor ID**: An optional ID used as an in-page link target. Enter it without the `#` symbol (e.g., `find-your-shape`). A hero button can then link to `#find-your-shape`
- **Color scheme**: The section's color scheme

## Blocks

### Navigation card

Adds one card. There is no limit on the number.

- **Image**: The card's image. To keep silhouettes consistent, use images with transparent backgrounds or full-body shots
- **Title**: The card's title (e.g., Straight)
- **Body**: The card's description
- **Link**: Where the card links (a collection page, for example)

<Note>
Consistent silhouettes across card images make choosing noticeably easier. Transparent-background PNGs shot at the same position and size work best.
</Note>
