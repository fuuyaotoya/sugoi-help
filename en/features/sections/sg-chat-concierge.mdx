An AI chat concierge that opens from the launcher at the bottom-right of the screen. It answers questions about sizing, gifts, and shipping in conversation, and shows its sources (product data, delivery rules, and so on). For an introduction and app-side setup, see the [SUGOI Chat integration guide](/en/integrations/sugoi-chat).

## How to add

In the theme editor (Admin → **Online Store → Themes → Customize**), open the footer area and choose **SUGOI AI Chat** from "Add section".

<Warning>
To show the chat, first set **AI chat connection URL** under **Theme settings → AI chat**. While the URL is empty, this section renders nothing (no risk of misbehavior). See [AI chat (theme settings guide)](/en/theme-settings/chat) for details.
</Warning>

## Settings

- **Greeting**: The first message shown when the chat opens. Leave empty to use the default greeting
- **Chat display name**: The name shown at the top of the panel. Leave empty to use "AI Concierge"
- **Launcher icon image**: Replaces the bottom-right chat button icon with an image. Leave empty to use the standard icon
- **Color scheme**: The panel color scheme
