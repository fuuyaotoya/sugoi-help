A hero section for the brand introduction at the top of an About page. Alongside a small English-style label, a large heading, an accent line, and introductory text, key figures such as the free-shipping threshold or fastest dispatch can be laid out as a "stats strip."

![The about hero section](/en/images/sg-about-hero.png)

## How to add it

Open the theme editor (in the admin: "Online store → Themes → Customize"), and in the template of the page you use for About, choose **"About hero"** from "Add section". It can be added to any page type (except header and footer areas). Proven on About pages (the `page.about` template).

<Note>
This section's heading renders as the page's H1 (top-level heading), so place only one per page.
</Note>

## Settings

- **Eyebrow label**: A small gold English-style label shown above the heading. Hidden when blank
- **Heading**: Rendered as the page's h1 (default: ABOUT). Place only one per page
- **Accent line**: The serif italic (gold) line beneath the heading. Hidden when blank
- **Brand introduction**: The text introducing the page (rich text)
- **Image (optional)**: An image placed beneath the introduction. The section works without one
- **Color scheme**: The section's color scheme
- **Padding (top) / Padding (bottom)**: Padding above and below the section (default 52 / 44)

## Blocks

### Stat (limit 8)

A "value plus description" pair shown side by side beneath the heading. Use it for the practical numbers shoppers care about — the free-shipping threshold, fastest dispatch, order cutoff times.

- **Value**: The figure itself (e.g., ¥15,000)
- **Label**: The short description beneath the value (e.g., The amount at which all orders ship free)

<Note>
The stats strip is meant for store-specific practical conditions, so the theme ships with no defaults. Left blank, only the stats strip itself is hidden — the page still stands.
</Note>
