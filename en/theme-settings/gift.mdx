## Gift & noshi settings

Stores with gift demand (wagashi, flowers, beverages, and so on) can add **noshi, wrapping, name imprinting, and message** input to the buy form on the product page. What shoppers choose carries through to the cart and the order.

In the theme editor, open **Theme settings → Gift & noshi**.

## On / off

**Show gift & noshi input** — Checking this adds gift input to the product page's buy form. Leave it off for stores that don't need it. OFF by default.

## Displayed items (each category can be shown or hidden individually)

**Let shoppers choose the noshi type** — Shows a selector for the noshi type, such as a bow knot or a tight knot.

**Noshi type options (override)** — Enter one option per line to replace the defaults. Blank keeps the defaults (bow knot, tight knot, Awaji knot).

**Let shoppers choose the inscription** — Shows a selector for the gift inscription, such as a celebration or a return gift.

**Inscription options (override)** — One option per line. Blank keeps the defaults (celebration, return gift, thank-you, casual gift, plain).

**Let shoppers choose inner or outer noshi** — Shows a selector for how the noshi is applied. Turn off if you don't handle this distinction.

**Let shoppers choose the wrapping type** — Shows a selector for the wrapping type, such as ribbon wrap or gift box.

**Wrapping type options (override)** — One option per line. Blank keeps the defaults (ribbon wrap, gift box, gift bag).

**Show the name imprinting field** — Shows a field for the name to print on the noshi or wrapping. Turn off if you don't handle name imprinting.

**Show the message field** — Shows a field for writing a gift message. If you use it, set the character limit below.

## Message card

**Maximum message length** — 0 for no limit (default 100).

**Wrapping note** — Enter a note such as a free-wrapping announcement. Hidden when blank.

<Note>
Gift options entered by shoppers are visible on the cart page, in order confirmation, and in the admin's order details. To show them in the order confirmation email, you need to add the attributes to Shopify's notification template.
</Note>
