## What the theme license is

SUGOI Theme uses a simple license model: **one purchase, one store**. The purchaser registers the store using the theme in theme settings. Do not distribute the theme files to other stores. Access to the AI chat and my-account apps is not controlled by this setting.

## How to set it

1. In the theme editor, open **Theme settings → Theme license**
2. Under **myshopify.com domain of the store using this theme**, enter the one permanent domain of the store that will use this theme (e.g., `your-store.myshopify.com`)

<Warning>
Even if your store is published on a custom domain, enter the **myshopify.com domain**. If the value does not contain ".myshopify.com", the theme will not render its content on regular published pages.
</Warning>

If the entered domain differs from the actual store, display does not stop — but please honor the one-purchase, one-store terms of use.
