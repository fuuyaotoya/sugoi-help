SUGOI Theme stands complete on its own, but combined with the **SUGOI Chat** app, an AI chat concierge comes alive on your storefront. After hours, the chat greets visitors the way a staff member would — a concierge that resolves the three points where shopping stalls (size, gifting, and delivery) through conversation.

![Cart page](/images/phase3-cart.png)

## What it can do

<CardGroup cols={2}>
  <Card title="Size consulting" icon="ruler">
    Size candidates narrowed down in conversation carry over to the product page's size selection. Hesitation never makes it back to the page.
  </Card>
  <Card title="Gift consulting" icon="gift">
    From suggesting the right gift inscription for the occasion to settling the noshi placement (inner or outer) and packaging type, everything is confirmed in conversation and carried into the order flow.
  </Card>
  <Card title="Delivery and timing answers" icon="truck">
    Answers to "Will it arrive in time?" come from the same rules as the product page's delivery estimate. The design never improvises an answer.
  </Card>
  <Card title="Search by image" icon="camera">
    Visual search that suggests similar products from photos shoppers take themselves.
  </Card>
  <Card title="Order status lookup" icon="package">
    For signed-in shoppers, the chat answers the delivery status of their recent orders (WISMO — "Where is my order?").
  </Card>
  <Card title="FAQ-grounded answers" icon="book">
    Delivery and returns questions are answered from the text of your published FAQ. The chat never invents policy.
  </Card>

It also handles best-seller ranking questions, outfit suggestions, product consultations comparing favorites, and escalation to human support (only for answers that could not be grounded in a source). Every reply carries a source chip — such as "Source: product data / delivery rules" — so shoppers can verify where the answer came from.

## Enabling it on the theme side

After installing the SUGOI Chat app on your store, connect it from the theme:

1. Install SUGOI Chat and note the chat backend endpoint URL
2. In Theme settings → **SUGOI AI chat**, set the URL in `sg_chat_endpoint`
3. Save

Until it is configured, the chat UI **outputs nothing** (a fail-closed design). You can proceed with other settings without worrying about misfires.

## Key theme-side settings

| Setting | Where | Meaning |
|---|---|---|
| `sg_chat_endpoint` | Theme settings | Chat backend URL. Unset = hidden |
| `sg_chat_streaming` | Theme settings | Whether to use streaming display (SSE) |
| `sg_chat_customer_hint` | Theme settings | Send a logged-in customer hint (default OFF) |
| `sg_chat_order_context` | Theme settings | Send recent-order context needed for order-status answers (default OFF; designed to exclude personal information) |
| `sg_chat_cart_attributes` | Theme settings | How chat-driven sales are measured (off / ajax / backend) |
| `sg_chat_save_preferences` | Theme settings | Consent-based preference-saving UI (default ON) |
| `sg_chat_context_recent` | Theme settings | Use "recently viewed products" as chat context (default ON) |
| `sg_chat_ranking_collection` | Theme settings | Source collection for ranking answers |
| `sg_chat_looks_collections` | Theme settings | Source collections for outfit suggestions (CSV) |
| `greeting` | Section settings | Opening greeting text (blank = default message) |
| `color_scheme` | Section settings | Panel color scheme |

## Delivery rule synchronization

The chat's delivery-date calculation and the theme's delivery estimate badge (`i-delivery-promise`) run on the **same algorithm and the same data**. The rules JSON for holidays and region-specific shipping days is shared between the theme and the chat backend, so "the product page and the chat disagree" is structurally impossible.

See [Metafield setup](/en/setup/metafields/definitions) for the delivery metafield definitions (production days and shipping class). If you change the rules, the `delivery-rules.json` on both sides must be updated together (theme-side updates are delivered to you by the provider).

## Privacy and safe design

- All chat reply text and product data are strictly safe-rendered (no HTML injection possible)
- Order-status answers use only the minimum — order number, status, tracking URLs. Names, addresses, email addresses, and phone numbers are never included
- Shopper preferences (such as size) are saved only when the on-screen consent checkbox is ON
- Settings that would pass personal information to the AI (`sg_chat_customer_hint` / `sg_chat_order_context`) default to OFF
