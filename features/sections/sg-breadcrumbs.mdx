お客様が今いるページまでの階層（ホーム → コレクション → 商品 など）を示すパンくずリストを表示するセクションです。検索エンジン向けの構造化データ（BreadcrumbList）も出力でき、SEO に役立ちます。

## 追加方法

テーマエディタ（管理画面の「オンラインストア → テーマ → カスタマイズ」）を開き、追加したいページの「セクションを追加」から**「パンくずリスト」**を選択します。**商品・コレクション・ブログ記事・固定ページ**のテンプレートで追加できます。About や FAQ などのページテンプレートでの使用実績があります。

<Note>
商品ページの親コレクションは、管理画面で商品に登録したコレクションの順で最初のものが使われます。意図したコレクションが表示されない場合は、商品の編集画面でコレクションの登録順を確認してください。
</Note>

## 設定

- **パンくずリストを表示する**: パンくずリストの表示 ON / OFF を切り替えます（既定 ON）
- **構造化データ（JSON-LD）を出力する**: 検索エンジン向けに BreadcrumbList の構造化データを出力します（既定 ON）。他のセクションが同じ構造化データを出力している場合は重複を避けるため OFF にしてください
- **HOME ラベル**: 一番左の項目の文言です。空白にすると翻訳の既定値（ホーム）が使われます
- **区切り文字**: 項目の間の記号を「› （シェブロン） / / （スラッシュ） / → （矢印） / — （ハイフン）」から選びます（既定: シェブロン）
- **配色**: セクション全体のカラースキームです
- **上 / 下**: セクション上下の余白です（既定 8 / 8）
