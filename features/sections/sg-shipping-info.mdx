地域別の送料・お届け日数を表形式で表示するセクションです。配送業者名や送料無料のしきい値も案内でき、配送情報ページやカートページでの使用に適しています。行のデータはメタオブジェクトから読むか、ブロックで手入力できます。

## 追加方法

テーマエディタ（管理画面の「オンラインストア → テーマ → カスタマイズ」）を開き、追加したいページの「セクションを追加」から**「配送・送料情報」**を選択します。どのページ種別にも追加できます（ヘッダー・フッターエリアを除く）。配送情報ページとカートページでの使用実績があります。

<Warning>
表示される送料は店舗が入力した**目安**です。実際の金額はチェックアウトで確定します。この注意書きは表と一緒に常に表示され、設定で消すことはできません。
</Warning>

## 設定

- **見出し**: セクションの見出しです（既定: 配送・送料について）
- **リード文**: 表の前に表示する説明文です。空欄で非表示になります
- **配送業者名**: 利用している配送業者名を入力します。ストアごとに異なるためテーマ側の初期値はありません。空欄で非表示になります
- **配送業者のリンク先**: 配送業者名にリンクを設定します。空欄の場合はテキストのみ表示します
- **送料無料のしきい値を表示**: テーマ設定（カート → 送料無料バーのしきい値）に設定した金額を表示します。商品ページでは購入ボタン下の案内が同じ金額を出すため、既定はオフです。配送情報ページに置くときだけオンにしてください（既定 OFF）
- **お届け日数の列を表示**: 表にお届け日数の列を表示します（既定 ON）
- **データ取得元**: 「自動（推奨）/ メタオブジェクト / ブロック（手入力）」から選びます。自動はメタオブジェクト → ブロックの順で探し、いずれも空の場合は送料表を表示しません（既定: 自動）
- **配送ゾーンのメタオブジェクト**: `shipping_zone` タイプのメタオブジェクトを選びます。1エントリが1行になり、フィールドキーは region / fee / fee_text / eta / note です。定義がストアに無い場合はここを空のままにして、ブロックで手入力してください（定義は管理画面の「設定 → カスタムデータ → メタオブジェクト」で作成します）
- **配色**: セクション全体のカラースキームです
- **上 / 下**: セクション上下の余白です（既定 36 / 36）

## ブロック

### 地域別送料の行

送料表の1行です。

- **地域名**: 行の対象地域です（例: 本州）
- **送料**: 送金額を入力します。カート合計と同じ通貨最小単位で入力するため、**日本円は100倍の数値**になります（800円なら `80000`）。0 のままにすると下の「送料の表示テキスト」が使われます
- **送料の表示テキスト**: 「送料無料」「実費」「800円〜」など金額で表せない場合に入力します。入力すると上の数値より優先されます
- **お届け日数**: 「2〜3日」などを入力します。テーマが根拠のない日数を表示しないため、初期値はありません。空欄のままなら日数セルは表示されません
- **備考**: 行に添える補足です

### 代引手数料の行

代引き（COD）の手数料表の1行です。注文金額帯ごとの手数料を並べられます。

- **ご注文金額**: 手数料が適用される注文金額の範囲です（例: 10,000円まで）
- **手数料**: 手数料を入力します。送料と同じく通貨最小単位で、**日本円は100倍**になります（330円なら `33000`）。0 のままにすると下の「手数料の表示テキスト」が使われます
- **手数料の表示テキスト**: 金額で表せない場合の表示テキストです

### 補足

表の下に置く補足テキストです（リッチテキスト）。

- **補足テキスト**: 追加送料の案内など（既定: 地域により追加料金がかかる場合があります。）

<Note>
送料の数値を間違えやすいのは通貨単位です。日本円は「円」ではなく「分」（1/100円単位）で入力するルールが Shopify 全体で共通です。不安な場合は数値ではなく「送料の表示テキスト」で「800円」と直接書く方法もあります。
</Note>
