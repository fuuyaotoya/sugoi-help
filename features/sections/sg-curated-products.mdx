お店が厳選した商品を1点ずつ手で選んで並べるセクションです。商品ごとに差し替え画像・短い表示タイトル・キャプションを設定でき、「なぜこの商品をおすすめするのか」を添えた訴求向きのグリッドになります。

## 追加方法

テーマエディタ（管理画面の「オンラインストア → テーマ → カスタマイズ」）を開き、追加したいページの「セクションを追加」から**「おすすめ商品」**を選択します。どのページ種別にも追加できます（ヘッダー・フッターエリアを除く）。トップページでの使用実績があります。

## 設定

- **アイブロウ**: 見出しの上に小さく表示するラベルです（既定: 厳選したラインナップ）
- **見出し**: セクションの見出しです（既定: 毎日に寄り添うアイテム）
- **一覧リンクのラベル**: 見出しの横に置く「すべて見る」リンクの文言です（既定: すべて見る）
- **一覧リンク**: リンク先の URL です（コレクションページなど）
- **配色**: セクション全体のカラースキームです
- **画像比率**: 商品画像の縦横比を「画像に合わせる / 縦長（4:5） / 正方形 / 横長（4:3）」から選びます（既定: 縦長）
- **画像内側の余白**: テーマ設定の「写真まわりの余白」を基準に、このセクションだけ 0〜200% で調整します。0% で余白なしになります（既定 100）
- **上 / 下**: セクション上下の余白です（既定 64 / 64）

## ブロック

### 商品

表示する商品を1点追加します。数に上限はありません。

- **商品**: 表示する商品を選択します
- **差し替え画像**: 空欄の場合は商品画像を使用します。商品登録画像とは別の画像を並べたいときに設定します
- **短い表示タイトル**: 空欄の場合は商品名を使用します。グリッドで読みやすい短い表記にしたいときに設定します
- **キャプション**: 商品の下に添える短い説明文です（例: 一番選ばれている定番）

<Note>
「おすすめ商品」は手動選択型です。自動で商品が並ぶわけではないため、ラインナップの変更はこのセクションでブロックを差し替えて行います。並び順はドラッグで変更できます。
</Note>
