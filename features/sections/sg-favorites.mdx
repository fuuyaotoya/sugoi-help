お気に入りに追加した商品を一覧表示するページ用セクションです。お気に入りはお客様のブラウザに保存されるため、**ログイン不要・ゲストでも利用できます**（商品カードのハートボタンで追加します）。

一覧から2〜3点を選ぶと**比較表**が開き、価格・在庫・スペックを横並びで確認できます。さらにその内容をAIチャットに引き継いで相談したり、そのままカートに追加したりできます。

## 主な機能

- **お気に入り一覧** — 追加した商品をグリッドで表示。価格は表示時に最新へ再取得します
- **比較表** — 選んだ2〜3点の価格・在庫・スペック行を横並びで表示
- **バリアント選択とカート追加** — 比較表からサイズ・色を選んでカートへ追加できます（売り切れは選択不可）
- **AIチャットへの引き継ぎ** — 比較内容を添えて「コンシェルジュに聞く」ボタンから相談できます

## 比較表の内容

| 行 | 内容 |
|---|---|
| 価格 | 表示時に再取得した現在の価格。価格差がある商品は範囲表示、比較対象価格があればセール表示 |
| 在庫 | オプションが1軸の商品は購入可能な値を列挙、複数軸の商品は選択可能な組合せ数を表示 |
| スペック行（ブロックで追加） | 各商品のメタフィールドから表示。値が無い商品は「情報なし」になり、勝手に補完されることはありません |
| バリアント | 商品ごとにプルダウンで選択（売り切れは選択不可） |
| 操作 | 商品ページを開く／カートに追加 |

<Note>
価格はお気に入り追加時のものを使わず、表示時に最新を再取得します。値上げ・セールが反映され、削除・非公開になった商品は「取扱終了」として表示されます。
</Note>

## AIチャットへの引き継ぎ

比較表の「コンシェルジュに聞く」を押すと、選択中の商品とスペック比較の内容を添えてAIチャットが開き、相談を始められます。引き継いだ内容は一定時間（1時間）で失効します。

チャット機能がページに無い場合はボタン自体が表示されず、比較・購入だけの機能として動作します。チャット連携の詳細は [SUGOI Chat 連携](/integrations/sugoi-chat) を参照してください。

## 使い方

1. Theme Editor でお気に入り用ページを開き、「お気に入り一覧」セクションを追加します（1ページに1つまで配置できます）
2. 比較表に載せるスペック行（素材・サイズ感など）をブロックで追加します
3. スペック行は各商品のメタフィールドを読むため、管理画面の「設定 → カスタムデータ → メタフィールド」で定義・入力してください

## セクション設定一覧

| 設定 | 型 | 既定 | 説明 |
|---|---|---|---|
| 見出し | テキスト | 空 | 空欄なら既定の文言になります |
| 見出しを表示 | チェックボックス | ON | ページタイトルと二重になる場合はオフにします |
| 「商品を見る」リンク先 | URL | 空 | お気に入りが空のときに表示するボタンのリンク先 |
| 比較を有効にする | チェックボックス | ON | 2〜3点の比較とチャット引き継ぎを提供します |
| メタフィールド namespace | テキスト | 空 | スペック行を読む namespace。空欄でテーマ設定の共通 namespace（既定 `custom`）を継承します |
| メタオブジェクト参照キー | テキスト | 空 | 任意。商品メタフィールドの値がメタオブジェクト参照の場合、その値からも行データを探します |
| カラースキーム | カラースキーム | scheme-1 | セクションの配色 |

## ブロック

### スペック行（compare_row / 上限8）

比較表に1行追加します。

| 設定 | 型 | 既定 | 説明 |
|---|---|---|---|
| 行ラベル | テキスト | 空 | 比較表の行見出し（例: 素材） |
| メタフィールドキー | テキスト | 空 | 各商品のメタフィールドから読み取るキー。値が空の商品は「情報なし」表示になります |

## トラブルシューティング

**お気に入りが他の端末に引き継がれない**

お気に入りはお客様のブラウザに保存されるため、端末間で同期されません（仕様）。会員データとして保持したい場合は、アカウント連携の機能をご検討ください。

**比較表のスペックが「情報なし」になる**

スペック行に対応するメタフィールドがその商品に入力されていないためです。値が無いセルは空欄や推測値で埋められず「情報なし」と表示されます。namespace とキーの指定が正しいかも確認してください。

**カートに追加ボタンが押せない**

バリアント（サイズ・色など）が未選択、または選択したバリアントが売り切れの場合は押せない仕様です。
