特定商取引法に基づく表記（特商法表記）を表示する専用セクションです。日本の EC では通信販売事業者に表示義務がある法定項目を、定義リスト形式で並べます。

セクションは**項目名（表示すべき内容）の枠組み**を提供するだけで、表示される内容はすべて店主が入力したものです。

<Warning>
このセクションが表示する内容の法的妥当性は、店舗運営者の責任です。虚偽や古い情報のままの表記は、特定商取引法（第11条）および景品表示法違反になり得ます。テーマにサンプル事業者データは一切同梱されていないため、すべての項目をご自身の実データで入力してください。法改正への追従も、顧問弁護士等とご確認ください。
</Warning>

## 法定項目（特定商取引法第11条・通信販売）

同梱のページテンプレート（`page.tokushoho`）が、以下の13項目を項目名付きで予め並べます。店主は内容（value）を埋めるだけです。送料・返品・不良品の3項目は強調表示が推奨されます。

| # | 項目名 | 根拠 |
|---|---|---|
| 1 | 販売事業者名 | 氏名又は名称 |
| 2 | 運営責任者 | 代表者の氏名 |
| 3 | 所在地 | 住所 |
| 4 | 電話番号 | 電話番号 |
| 5 | メールアドレス | 電子メールアドレス |
| 6 | 受付時間 | 営業時間 |
| 7 | 販売価格 | 販売価格 |
| 8 | 送料（強調） | 代金以外に負担させる費用 |
| 9 | 支払方法 | 対価の支払い時期・方法 |
| 10 | 商品代金以外の必要料金 | 代金以外に負担させる費用 |
| 11 | 引渡時期 | 商品の引渡時期 |
| 12 | 返品・交換（強調） | 申込みの撤回・解除（返品特約） |
| 13 | 不良品対応（強調） | 不良品の取扱 |

## 使い方

1. Shopify 管理画面でページを作成し、タイトルを「特定商取引法に基づく表記」などにします
2. ページのテンプレートに `page.tokushoho` を選ぶと、法定13項目の枠が項目名付きで並びます
3. Theme Editor で各項目の内容を埋めます。入力し忘れた項目は空欄の行として表示されます
4. 最終更新日を公開日に設定します

Theme Editor からセクションを単体で追加することもできます（空の項目が1つ付いた状態で追加されます）。

## ブロック

### 項目（row / 上限30）

表記の1行になります。

| 設定 | 型 | 既定 | 説明 |
|---|---|---|---|
| 項目名 | テキスト | 項目名 | 例: 販売事業者名 |
| 内容 | テキストエリア（複数行可） | 空 | 事業者の実データを入力します |
| 重要項目として強調表示 | チェックボックス | OFF | オンにすると左側にアクセントバーと薄い背景色が付き、読み飛ばされにくくなります（送料・返品・不良品などに推奨） |

## セクション設定一覧

| 設定 | 型 | 既定 | 説明 |
|---|---|---|---|
| 見出し | テキスト | 特定商取引法に基づく表記 | ページの見出し |
| 最終更新日 | テキスト | 空 | 例: 「最終更新: 2026年5月13日」。空欄で非表示 |
| お問い合わせカード: 見出し | テキスト | ご不明な点はお問い合わせください | 表の下のカードに表示 |
| お問い合わせカード: 受付時間 | テキスト | 空 | 例: 「平日 10:00-18:00」。空欄で非表示 |
| お問い合わせカード: ボタンの文言 | テキスト | お問い合わせフォームへ | カード内のボタン |
| お問い合わせカード: ボタンのリンク先 | URL | 空 | 通常はお問い合わせフォームのページを指定します |
| カラースキーム | カラースキーム | scheme-1 | セクションの配色 |
| 上下の余白 | 範囲（px） | 36 / 36 | セクションの余白 |

お問い合わせカードは、見出し・受付時間・ボタンの文言・リンク先が**すべて設定されている場合にのみ**表示されます。不要なら項目を空欄のままにしてください（リンク先未設定の場合、ボタンは `#` になります）。

## トラブルシューティング

**入力していない項目が空欄で表示される**

仕様です。項目単位で非表示にするのではなく、未入力の行も空欄のまま出力されます。すべての項目を埋めて公開してください（空欄のまま公開すると、表示漏れとして法的リスクになります）。

**お問い合わせカードが表示されない**

見出し・受付時間・ボタンの文言・ボタンのリンク先の4項目がすべて入力されているか確認してください。1つでも空欄があるとカード全体が表示されません。
