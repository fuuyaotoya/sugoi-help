title: クイックビュー
description: 商品一覧の「クイックショップ」ボタンから開くモーダルの中身を提供するセクション。バリアント選択と購入ボタンをコンパクトに表示します
---

商品一覧などのカードに置かれたクイックビューボタンを押したときに開く、モーダル（吹き出しウィンドウ）の中身を提供するセクションです。ページ上に見えている部分はなく、モーダルの中にコンパクトな商品情報（バリアント選択・購入ボタン）を表示します。お客様はページ遷移なしでその場で購入まで進められます。

## 追加方法

テーマエディタ（管理画面の「オンラインストア → テーマ → カスタマイズ」）を開き、**商品ページ**のテンプレートで「セクションを追加」から**「クイックビュー」**を選択します。

<Warning>
このセクションは**商品ページのテンプレートに配置する必要があります**。モーダルの内容は商品ページの URL を通じて取得されるため、商品テンプレートから外すと、一覧ページなど全ページでクイックビューが動かなくなります。商品ページ上でこのセクション自体は表示されません（モーダル専用の不可視セクションです）。
</Warning>

## 設定

- **ブランドを表示**: モーダル内に商品ベンダー（ブランド名）を表示します（既定 ON）
- **配色**: モーダル内のカラースキームです

## ブロック

### バリアントピッカー（1個まで）

サイズ・色などのバリエーションを選ぶ UI です。

- **スタイル**: 選択 UI の見た目を「ピル型ボタン」「ドロップダウン」から選びます（既定: ピル型ボタン）

### 購入ボタン（1個まで）

カートに追加するボタンです。

- **動的チェックアウトボタン**: お客様に希望する支払いオプション（Shop Pay など）を表示します（既定 OFF）

<Note>
クイックビューの起動ボタンは商品カード側の設定で制御されます。このセクションは「開いたときの中身」だけを担当します。
</Note>
