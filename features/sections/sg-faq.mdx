よくあるご質問（FAQ）ページを表示するセクションです。質問の正本は **`faq_entry` メタオブジェクト**で、Theme Editor での質問入力欄は持ちません。管理画面の「コンテンツ → メタオブジェクト」で登録・公開した質問が、自動で全件表示されます。

SUGOI Chat を導入しているストアでは、AIチャットのFAQ回答も同じデータから返ります。画面に表示されていない（下書きの）質問にAIが勝手に答えることはありません（[SUGOI Chat 連携](/integrations/sugoi-chat)）。

## 主な機能

- **自動全件表示** — 公開済みの `faq_entry` をすべて表示。表示/非表示の個別設定は不要で、メタオブジェクトの公開状態（下書き / 公開）だけで制御できます
- **検索ボックス** — 質問・回答テキストからの絞り込み（お客様のブラウザ内で動作します）
- **カテゴリ絞り込み** — 質問の `category` フィールドからカテゴリチップを自動生成します
- **FAQPage 構造化データ** — 質問・回答を schema.org の FAQPage として出力し、検索エンジンのリッチリザルト表示に対応します
- **お問い合わせバンド** — 質問リストの下にお問い合わせへの誘導カードを表示できます

## 使い方

1. `faq_entry` メタオブジェクトの定義を作成します(管理画面の「設定 → カスタムデータ → メタオブジェクト」で作成します)
2. Shopify 管理画面の「コンテンツ → メタオブジェクト → faq_entry」で質問を登録し、**公開**します
3. 管理画面でページを作成し、テンプレートに `page.faq` を選びます（FAQ 用テンプレートが同梱されています）
4. Theme Editor でお問い合わせバンドのリンク先（通常は `/pages/contact` など）を設定します

<Note>
下書きのままの質問はストアフロントに表示されません。公開操作がそのまま「サイトに出してよい」の承認ゲートになります。AIチャットの回答も公開済みの質問だけを根拠にします。
</Note>

## メタオブジェクトのフィールド

`faq_entry` に必要なフィールドは次のとおりです。

| キー | 型 | 用途 |
|---|---|---|
| `question` | 1行テキスト | 質問文。空の質問は表示・件数から除外されます |
| `answer` | リッチテキスト | 回答本文 |
| `category` | 1行テキスト | カテゴリ名。空なら見出し無しの末尾グループに表示されます |
| `sort_order` | 数値 | 表示順 |
| `source` | 1行テキスト | 出典メモ（管理用）。ストアフロントには出力されません |

### カテゴリの運用

カテゴリのチップとグループ見出しは、質問の `category` から自動生成されます。表記ゆれでチップが増えるのを防ぐため、以下の正規ラベルで運用することをおすすめします。

| ラベル | 想定内容 |
|---|---|
| 注文・決済について | 注文手順・決済方法・キャンセル・変更 |
| 配送について | 送料・お届け日数・追跡・ギフトラッピング |
| 商品・在庫について | サイズ・素材・在庫状況・再入荷 |
| 返品・交換について | 返品ポリシー・交換手順 |
| アカウント・会員について | ログイン・会員特典 |

カテゴリ未設定の質問は、見出し無しの末尾グループに表示されます。

### 表示順（sort_order）

`sort_order` は **10刻みで一意**にする（10, 20, 30, …）のがおすすめです。同じ値の並び順は保証されないため、一意にしておくと表示順が常に確定します。途中に挿入するときは中間値（15 など）ではなく、以降を繰り下げて10刻みを保ってください。

## セクション設定一覧

| 設定 | 型 | 既定 | 説明 |
|---|---|---|---|
| リード文 | リッチテキスト | 空 | 質問リストの前に表示する説明文。空欄で非表示 |
| 検索ボックスを表示 | チェックボックス | ON | JavaScript が無効な環境では表示されません（質問リストは表示されます） |
| カテゴリーの絞り込みを表示 | チェックボックス | ON | 有効なカテゴリーが2つ未満の場合は表示されません |
| 最初の質問を開いた状態にする | チェックボックス | OFF | ページ表示時に最初の質問だけ回答を展開します |
| お問い合わせバンドを表示 | チェックボックス | ON | リンク先が空の場合は表示されません |
| お問い合わせページのリンク先 | URL | 空 | 通常は `/pages/contact` などを指定します |
| チャットへの案内を表示 | チェックボックス | ON | テーマ設定のチャットエンドポイントが設定されているときだけ表示されます |
| FAQPage 構造化データを出力 | チェックボックス | ON | 質問・回答を schema.org の FAQPage として出力します |
| カラースキーム | カラースキーム | scheme-1 | セクション本体の配色 |
| お問い合わせバンドのカラースキーム | カラースキーム | scheme-3 | バンドの配色。既定は反転色です |
| 上下の余白 | 範囲（px） | 36 / 48 | セクションの余白 |

## トラブルシューティング

**FAQ が1件も表示されない**

次のいずれかが原因です。

- `faq_entry` メタオブジェクトの定義が作成されていない
- 質問がすべて下書きのまま（公開されていない）
- `question` フィールドが空のまま

**カテゴリの絞り込みチップが出ない**

カテゴリが設定された質問が2件以上あるか確認してください。有効なカテゴリーが2つ未満の場合はチップ自体が表示されません。

**表示順が入れ替わる**

`sort_order` に重複する値がないか確認してください。同じ値の並び順は保証されません。
